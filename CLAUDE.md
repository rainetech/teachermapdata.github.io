# Keep this repository generic

This is the open version of the dashboard. Nothing in it should name, link to
or describe any particular school, organisation or hosting setup: no deployment
URLs, project or team IDs, logos, brand colours, or scripts that build a
branded copy. Those belong in the deployment's own repository, not here. The
same goes for commit messages, comments and pull request text.

If a change needs a hook for a branded copy, name the hook generically: a slot,
a token, an environment variable.

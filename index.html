Where do I find my ASG CSV? & what does this tool read?
Exporting from NWEA MAP Growth
  1. Sign in to MAP Growth and open MAP Reports.
  2. Choose the Achievement Status and Growth (ASG) report for your class and terms.
  3. Use the export/download option and select CSV.
  4. Return here and upload that file — nothing is sent anywhere.
Good to know
  • Column names are matched automatically, so slightly different exports still work.
  • Suppressed values (***) and missing scores are handled gracefully.
  • Not ready to export? Click Load Sample Data to explore every feature first.

Growth and Achievement

Uses NWEA growth/achievement quadrants when present, with an overall view and a subject breakdown.

What the quadrants mean High-G/High-A students are growing strongly and achieving highly. Low-G/Low-A students need the most immediate instructional attention.
Why this matters This separates achievement from growth, so a lower-scoring student with strong growth is not treated the same as a lower-scoring student with low growth.
How to read movement Improved, declined, and stayed same compare StartGrowthandAchievement to EndGrowthandAchievement for the same student-subject record.

Secure benchmark: 61st percentile. Overall cards are followed by subject-level gap patterns.

For students below 61 Gap closure measures how much of the distance to the secure benchmark was closed from start to end percentile.
For students at 61+ The dashboard checks whether secure students extended, maintained, regressed, or dropped below the secure benchmark.

Flexible Table Groups

Choose a group size and strategy to create classroom table assignments.

Use one number for even tables, or a pattern for uneven tables.
Bigger second number makes the room taller.
Subject-aware grouping If a subject filter is selected, each table uses that subject. If no subject is selected, each student's visible records are averaged into one planning profile.
Balanced mixed tables Spreads higher, middle, and lower complete profiles across tables. Missing-data students start in the manual pool.
Similar-score skill groups Clusters nearby scores for targeted small-group instruction. Highest-need first intentionally places the most urgent profiles into the first tables.
